Project Overview

What is Vocal Path?

A mobile ecosystem that automates stuttering detection and delivers clinician-grade, personalised speech therapy — accessible from anywhere in Sri Lanka.

The Problem

Diagnosis depends on manual SLP observation — slow, subjective, and inaccessible for rural children in Sri Lanka. No validated Sinhala stuttering model exists.

Our Solution

Cloud-based bilingual AI that detects stuttering from audio, recommends adaptive exercises, and tracks long-term therapy progress — no camera required.

Who It Helps

Children aged 5–10, parents monitoring progress at home, and Speech-Language Therapists needing data-driven patient insights.

System Architecture

Four Integrated AI Components

Each component independently addresses a critical clinical gap and works together as a seamless therapy platform.

Component 1 · IT22565044

Stuttering Detector

Bilingual binary classifier on Wav2Vec2 XLS-R 300M detecting stuttering from raw audio in English & Sinhala. Achieves 88.18% accuracy, F1 0.891. Downstream Random Forest stutter-type classifier: 98.34%.

Wav2Vec2 XLS-RMFCCs + PitchBilingual
Component 2 · IT22590862

Exercise Recommender

Hybrid rule-based + KNN ML recommender classifying severity (mild/moderate/severe). Dynamically adjusts exercise difficulty from historical performance, simulating clinician-guided therapy.

KNN AlgorithmAdaptive DifficultyCloud-Based
Component 3 · IT22563064

Pronunciation Feedback

Dual-fallback ASR (Whisper + Google Cloud STT) with IPA phoneme alignment and Levenshtein distance. SVM fluency classifier: 89.75% accuracy. Sub-300ms corrective feedback.

Whisper ASRSVM 89.75%en-US + si-LK
Component 4 · IT22273758

Progress Dashboard

LSTM time-series model forecasts fluency improvement across sessions. Deployed as a RESTful Flask service, visualised in a Flutter dashboard for children, parents, and clinicians.

LSTMReal-Time ForecastFirebase + Flutter
